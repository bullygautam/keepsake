Keepsake 5.1 AI fix

1. Extract the whole ZIP to a new folder.
2. Run INSTALL_AI_CUTOUTS_WINDOWS.bat while connected to the internet.
3. Restart with START_WINDOWS.bat.
4. Import photos and enable AI subject stickers.
5. First activation can take a while because the u2netp model downloads.
6. If it fails, run DIAGNOSE_AI_WINDOWS.bat and send AI_DIAGNOSTICS.txt.

Cutouts are experimental and currently use one selected photo per page.
Photos without clear foreground subjects may not cut out well.
